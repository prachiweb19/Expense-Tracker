# 💰 Expense Tracker

A simple and responsive Expense Tracker built using *React.js* that helps users manage their daily expenses and visualize spending trends.

---

## 🚀 Features
- Add, edit, and delete transactions  
- View total balance, income, and expense summary  
- Filter transactions by date or category  
- Fully responsive and modern UI  
- Data stored locally using browser’s Local Storage  

---

## 🧠 Tech Stack
- *Frontend:* React.js, HTML, CSS, JavaScript  
- *State Management:* useState, useEffect Hooks  
- *Storage:* LocalStorage  

---

## 📦 Project Setup

In the project directory, you can run:

### npm install
Installs all dependencies for the project.

### npm start
Runs the app in development mode.  
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.  
The page will reload when you make changes.

### npm run build
Builds the app for production to the build folder.
